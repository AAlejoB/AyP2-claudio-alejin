# 📚 AyP2 — Foro de Estudio · Claudio & Alejín

> Material de estudio de **Algorítmica y Programación II** (lenguaje **Ada**)
> de la UNPSJB, armado por Alejo + Claude Code.

## 🎯 Qué hay acá adentro

- **`index.html`** — El corazón del repo. Un foro autosuficiente (~412 KB,
  sin dependencias externas) que se abre con doble click y contiene:
  - 📚 **Manual de Supervivencia** (5 posts teóricos: TAD, excepciones,
    estructuras compuestas, memoria dinámica, listas enlazadas)
  - 🛠️ **TP1 → TP5 resueltos** (todos los ejercicios obligatorios)
  - 📝 **Parciales viejos** (2023, 2024, 2025, recuperatorios — algunos
    resueltos, otros con enunciado para practicar)
  - 📋 **Cheat Sheet** de Ada (atributos, tipos, excepciones, genéricos,
    memoria, arrays, I/O, trampas de parcial)
  - 🏋️ **Ejercicios para resolver** con autosave en localStorage

- **Enunciados originales** de TPs y parciales (PDFs, .docx)
- **`CLAUDE.md`** — onboarding para Claude Code (contexto del proyecto)

## 🚀 Cómo usarlo

```bash
git clone https://github.com/AAlejoB/AyP2-claudio-alejin.git
cd AyP2-claudio-alejin
```

Después, doble click a `index.html` y listo. Funciona en cualquier
navegador, sin servidor.
